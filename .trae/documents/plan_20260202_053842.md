## DrawToday 项目重构计划

### 一、技术栈统一
- **主框架**: React 18 + TypeScript + Vite
- **路由**: React Router v6
- **状态管理**: React Context + useReducer
- **UI库**: Tailwind CSS (已有) + Lucide React 图标
- **存储**: IndexedDB (保持) + localStorage

### 二、项目结构重构
```
src/
├── components/          # 通用组件
│   ├── ui/             # 基础UI组件
│   ├── layout/         # 布局组件
│   └── features/       # 功能组件
├── contexts/           # Context providers
├── hooks/              # 自定义Hooks
├── pages/              # 页面组件
├── services/           # API服务
├── utils/              # 工具函数
├── types/              # 类型定义
└── styles/             # 样式文件
```

### 三、核心改进点

#### 1. 路由系统
- 使用React Router替代自定义页面状态
- 实现嵌套路由支持
- 添加路由守卫（引导页检查）

#### 2. 状态管理
- 创建AuthContext（引导状态）
- 创建FoldersContext（图库数据）
- 创建SessionContext（练习会话）
- 使用useReducer进行复杂状态管理

#### 3. 平台检测
- 统一的环境检测工具
- Web/移动端条件渲染
- 渐进式Web应用(PWA)支持

#### 4. 错误修复
- 修复capacitor-utils.ts类型错误
- 统一IndexedDB操作逻辑
- 添加错误边界处理

### 五、验证步骤
1. 运行 `npm install` 更新依赖
2. 运行 `npm run build` 验证构建
3. 运行 `npm run dev` 测试网页端

### 六、迁移策略
- 分阶段重构，不影响现有功能
- 保持向后兼容
- 逐个模块重构和测试
